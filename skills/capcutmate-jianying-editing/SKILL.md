# CapCut-Mate 剪映口播精剪

# 首次使用与路径配置

首次安装并调用本 Skill 时，先向用户说明：本 Skill 用于中文口播视频的重录清理、无效留白压缩、原生可编辑字幕制作和剪映草稿验收；用户提供原始视频、口播稿和剪辑要求后，Skill 会先分析素材，再在剪映草稿中完成编辑与验收，默认不导出成片。

在首次处理任何素材前，必须让用户提供或确认本项目的以下路径，并在当前任务记录中使用这些路径变量：

- `SOURCE_MEDIA_DIR`：原始视频、音频、图片和口播稿的保存目录。
- `DRAFT_WORKSPACE_DIR`：剪映草稿及其稳定媒体引用所在的工作区。
- `BACKUP_WORKSPACE_DIR`：草稿备份、删减台账和中间审计文件的保存目录。
- `EXPORT_DIR`：用户明确要求导出时的成片或交付文件目录；默认不导出。

路径由用户指定，或从当前项目中明确识别后再确认；不得猜测、拼接或写入本机绝对路径，不得使用 Skill 安装目录、下载缓存或临时目录作为素材长期保存或时间线引用位置。若用户尚未确认路径，先说明用法和路径用途，暂停媒体读写，等待确认。后续同一项目默认复用已确认路径；换项目、换设备或路径失效时重新确认。

# 使用范围

本 Skill 用于中文口播视频的重录清理、无效留白压缩、原生字幕制作和剪映草稿验收，重点强化片段完整收尾、下一段开头留白和逐接口验收。

# 核心规则

1. 主内容视频放在剪映主轨，不能放到画中画轨道。配图和辅助视频放在画中画轨道。
2. 字幕使用剪映原生识别字幕对应的可编辑字幕格式，单独放在字幕轨道，不能把字幕烧录到画面中。底层字幕素材使用剪映字幕字段，包括 `type=subtitle` 和 `group_id=tse_subtitle`。
3. 首次制作新视频时，复制完整原始素材到新草稿目录，保留用户已有草稿和素材。
4. 片段使用完整原始素材的时间范围制作，保留素材前后可用内容，确保片段边缘可以继续延展。
5. 同一个视频后续修改时，默认在原来的剪映草稿中修改，不重复创建活动草稿。
6. 草稿名称遵循用户和项目的命名规则，使用视频主题命名，最多四个汉字。
7. 除非用户明确要求，不删除已有草稿。用户要求删除时，只处理已确认由本任务建立的目标草稿。
8. 默认不导出视频，完成后保留并打开目标草稿供用户检查。
9. 使用 CapCut-Mate 完成素材导入、时间线编辑、字幕写入和草稿保存；使用剪映查看最终波形、试听衔接并确认原生字幕可编辑。
10. 正常草稿列表只保留一个本任务目标草稿。中间版本如需留存，放在可恢复的备份位置。
11. 以用户提供的口播稿作为语义和字幕校对依据，以最终保留的实际录音作为字幕内容完整性和时间对齐的最终依据。
12. 语音识别、文本相似度、音量阈值和外部波形只用于定位问题和产生候选切点。重复内容取舍、片段边界和字幕交付以最终音轨、剪映实际波形、实际画面和逐句试听为准。
13. 字幕错字、漏字、漏句、多字、与声音不对应，以及未删除的重复录制，都属于不可交付项。
14. 草稿中的媒体使用用户确认的草稿工作区内的稳定路径，避免主轨长期引用临时目录、下载缓存或会被清理的外部路径。
15. 每次新增、替换或转码媒体后，同步维护 `draft_content.json` 与 `draft_info.json` 中的媒体记录，并按当前剪映版本各自的原生格式写入。
16. 字幕分句与视频切段分开判断。字幕可以按句义、标点和阅读长度分条，主视频轨不能因为字幕分条、换行或字幕起止点同步切段。连续口播中的自然换气、短暂停顿、强调和情绪停顿，应保留在同一个视频片段中。
17. 相邻视频片段来自同一连续录制，且源时间范围连续或间隔不超过零点五秒时，先按连续画面处理并合并视频片段。只有波形、口型、语义或重录清单确认存在错误、卡壳、重复录制、未说完重来或明确删减内容时，才保留视频切点。
18. 每个视频切点都要记录具体原因和证据。仅有“字幕开始”“字幕结束”“换了一句字幕”或“语音识别时间戳变化”时，不足以建立视频切点；字幕轨可以保持逐句可编辑，视频轨应保持自然连续。
19. 重复内容的删除必须是源视频、源音频和字幕三者同步的原子操作。字幕文字删掉但视频源时间范围仍覆盖该段录音时，视为未修复，不得交付。
20. 正式剪辑前建立删减台账，逐项记录原始源时间范围、识别文本或语义、重复或留白的判断依据、保留版本、删除版本、受影响字幕范围和复核结果。没有台账证据的切点不得写入最终草稿。
21. 无效留白必须同时检查片段之间、片段开头、片段结尾和保留片段内部。只检查相邻视频片段间隔，不能证明片段内部没有长空白。
22. 每次删减视频源范围后，必须重新计算后续视频片段的目标时间和字幕时间；禁止只改字幕时间或只改视频时间。最终以重建后的音频再次转写和波形扫描结果完成闭环校验。
23. 语音识别、波形和音量分析只能提供候选切点。每个候选点都要结合语义、词语时间戳、口型和实际试听分类为“应删除”“自然停顿”或“无法确定待确认”，不得把低音量自动等同于空白。

# 输入与首次配置

用户通常需要提供原始视频素材、口播稿和剪辑要求。首次使用时，先完成本 Skill 的路径配置，再确认剪映专业版、CapCut-Mate 和剪映本地适配层可用；将完整原始素材复制进用户确认的唯一新草稿工作区，完成一次短测试草稿，供用户在剪映中验证。首次配置确认后，后续任务默认接收新素材、口播稿和剪辑要求即可。

# 剪辑流程

### 一、先分析再剪辑

正式修改前，先完成以下分析：

1. 完整视频时间线。
2. 语音识别文本和词语时间戳。
3. 音频波形、静音、音量和环境音连续性。
4. 画面内容、人物动作、口型和镜头变化。
5. 每个视频片段的自然开头、自然结尾和相邻衔接关系。
6. 同一句话或同一个意群的多次录制情况。
7. 口播稿与实际录音的对应关系，标记脚本中未录出、录音中新增或识别不完整的内容。

处理顺序固定为：识别重录组，选择最佳版本，整体替换并删除其他版本；随后处理全片无效留白和所有片段接口；最后重新识别最终保留音轨，核对口播稿，生成完整且与最终音轨对齐的字幕。

处理重录前，先根据完整原片建立重录清单。清单至少记录每个重录组的所有时间范围、文本大意、录制状态、保留版本和删除版本。完成全片重录分组后，再开始最终剪辑。

开始实际删减前，建立“重复与留白删减台账”。台账中的每一项都必须能够回指原始素材的源时间范围；删除项必须同时标记视频、音频和字幕的处理状态。若只完成其中一项，状态保持为未完成。

### 二、处理多次重录

1. 将文本高度相似、前一遍卡壳或说错、后面重新完整表达的内容归为同一个重录组。
2. 比较同一重录组的所有完整版本。
3. 优先选择完整、流畅、发音清晰、情绪自然，并且与前后内容音量和音色匹配的版本。
4. 多个版本质量接近时，优先选择最后一个完整且状态稳定的版本。
5. 从自然开头到完整结尾整体替换错误版本。
6. 删除失败版本和多余版本，只保留一个最佳完整版本。
7. 保持一句话来自同一遍完整录制，避免把不同录制版本中的单个词拼成一句话。
8. 所有版本都不完整时，才允许局部修补，并优先按完整句子或意群处理。
9. 保留未被后续版本覆盖的有效铺垫、连接词、上下文和情绪。
10. 保留原本表达的内容和语义，不自行改写台词。
11. 最终音轨生成后，再次转写全片，同时检查相邻和不相邻句子的语义重复。除非口播稿明确要求有意重复，同一句话或同一个意思只保留一遍。
12. 对最终音轨从头到尾试听一遍，确认没有卡壳后重说、前后两个完整版本同时保留，以及含义基本相同的变体重复。
13. 将所有删除项从原始源时间范围映射到最终时间线，重新拼接最终保留音频，检查删除点前后文本是否连续、声音是否真的消失、字幕是否与保留声音对应。
14. 语义重复扫描必须覆盖不相邻片段，尤其检查开头重录、举例重说、半句重启、同义改说，以及字幕已删但视频声音仍在的情况。最终音轨仍出现同一句或同一意思的两次时，不能标记为完成。

### 三、处理无效留白与片段接口

1. 删除前一片段说完后到片段结束之间的等待、静音和无效画面，同时保留完整尾音。
2. 删除后一片段开始到开口说话之间的准备、停顿和无效画面，将片段起点到第一个有效音节的实际留白控制在零点零三秒以内。
3. 片段内部的自然换气、呼吸声和约零点一至零点五秒的短暂停顿通常保留。
4. 完整句子后的思考、强调、情绪表达和转场停顿可以保留，通常控制在零点四至一秒。
5. 没有语义作用且明显拖慢节奏的静音或空画面，尤其是超过零点六至零点八秒的部分，优先删除。
6. 剪辑点放在自然呼吸、句子开头或句子结尾，避开词语中间、音节中间和口型尚未结束的位置。
7. 通过调整片段边界压缩留白，保持词语、音节、语速和口型完整。
8. 保留背景音乐、环境音和必要的音频连续性。
9. 以剪映最终时间线的实际时长和视频帧精确检查。受帧率限制时，选择包含有效音节的画面帧，并通过试听确认首音完整。
10. 无法确定留白是否有意时，优先保留，并标记时间点供用户确认。
11. 完成留白处理后单独进行过切检查：逐一列出主视频轨切点，核对切点前后是否存在删除内容、重录切换、画面变化或明确的音频问题。连续口播仅因字幕分句产生的切点必须合并；如果主视频片段数量接近字幕条数，必须回看源时间范围并重新合并自然衔接处。
12. 对每个保留视频片段做内部留白审计：检查源片段开头到首个有效音节、最后有效音节到源片段结尾，以及句内所有连续低能量区。超过零点六至零点八秒且没有语义、情绪或转场作用的区域，必须删除或进入待确认清单。
13. 完成视频源范围调整后，把所有保留源片段按最终顺序拼接成临时审计音频，重新进行波形和语音扫描。若审计音频仍出现长空白，必须回到源片段定位并再次修改，不能只在字幕层补救。
14. 片段内部留白的删除不能通过把不同录音的前后半句直接拼接实现。若空白两侧属于不同重录，必须选择一遍完整录音，或保留整句并标记待确认。

### 四、优化上一个片段的结束

1. 从最后一个字开始观察波形包络，确认辅音、韵母、气声和口型已经完整结束。
2. 局部底噪是人没有说话时同一小段录音里的环境声和设备噪声。结尾波形回到局部底噪高度，并稳定保持一百至二百毫秒后，才能将这里作为候选结束点。
3. 不使用固定的负三十五分贝阈值，也不使用固定的零点零二秒、零点零三秒或零点二秒尾部余量。不同句子的尾音长度需要单独判断。
4. 如果结尾波形还在逐渐变矮，切点继续后移。语音识别给出的最后一个字结束时间只作为定位参考。
5. 如果下一遍重录马上开始，先在完整尾音和下一遍吸气或第一个字之间找切点。如果没有安全切点，改用同组的另一个完整版本；如果所有版本都没有安全切点，保留完整句子并向用户标注该位置。

### 五、优化下一个片段的开头

1. 在开口附近选取零点三至一秒的局部无人声区域，估计局部底噪，再结合词语时间戳、波形连续性和口型定位第一个有效音节。
2. 音量候选阈值使用局部底噪以上六至十分贝，不固定使用负三十五分贝。轻声首字、吸气和辅音可能低于候选阈值，必须通过波形和试听复核。
3. 候选开头写入草稿后，在剪映中放大时间线，以剪映最终波形测量从片段起点到第一个有效音节的留白。这个实际留白必须小于或等于零点零三秒。
4. 三十帧视频的一帧是零点零三三三秒。如果时间线只允许按帧移动，应选择包含第一个有效音节的那一帧，然后试听确认首音没有被截断。
5. 外部脚本计算得到的零点零一秒或零点零三秒只是候选值。完成剪映最终时间线的逐段验证后，才能汇报为已达标。

### 六、逐接口验收

对每个“上一段结束＋下一段开头”单独验收：

1. 在剪映中放大到能分辨帧和波形细节的级别。
2. 查看上一段的最后一个字、尾音、呼吸和口型，确认没有截断。
3. 查看下一段的第一个字和口型，测量实际开头留白。
4. 从接口前零点五秒播放到接口后零点五秒，确认听不出截字、突然断音、过长空白或废弃重录的开头。
5. 记录每个接口的上一段结束判断、下一段实际留白和验收结果。完成全部接口验收后，才能将整个草稿标记为完成。
6. 接口验收记录必须区分片段之间的空白和片段内部的空白；前者通过接口检查，后者通过源片段内部波形和最终审计音频检查，两项不能互相替代。

### 七、制作和验收字幕

字幕根据最终剪辑后的语音时间线生成，并保持可编辑。字幕识别覆盖实际录音的全部内容，字幕与声音的起止时间以最终音轨为准。

1. 完成重录清理和所有接口调整后，重新转写最终音轨，不复用剪辑前的旧字幕时间。
2. 通过 CapCut-Mate 写入剪映字幕轨道，并使用剪映原生识别字幕对应的字幕材料结构。
3. 以最终音频识别结果为内容基础，以口播稿校对明显的同音错字和专有名词。录音中没有说出的脚本内容不补入字幕，实际说出的口语词予以保留。
4. 在逗号、句号、顿号、问号、感叹号、分号、冒号和换行处切开字幕。
5. 从字幕文本中删除所有中文和英文标点符号。
6. 字幕片段首尾连续，片段之间没有时间空白或重叠。
7. 字幕只对应最终保留的最佳重录版本。
8. 字幕文字、声音、口型和画面保持同步。
9. 字幕分条不等于视频切段。字幕按句切开时，视频轨继续沿用连续口播片段；只有经过音频、画面和语义核对的删除点才切开视频。
10. 字幕素材使用剪映标准字幕类型 `subtitle`，并保留 `tse_subtitle` 字段标记；不能使用普通 `text` 类型、图片字幕或烧录字幕替代。
11. 若 CapCut-Mate 写入器生成了普通 `text` 类型，在交付前按照剪映原生字幕模板转换为 `subtitle`，并重新检查字幕数量、内容、样式和时间连续性。
12. 字幕初稿完成后，从头到尾播放最终草稿，逐句检查错字、漏字、漏句、多字、字幕提前、字幕滞后和分句错误。
13. 语音识别没有报错，不能代替字幕验收。最终必须完成逐句试听。
14. 字幕验收必须以最终保留音频为准。若字幕显示的文本已经删除，但最终音频转写仍能识别出对应重复内容，必须回到视频源范围删除该录音后重新生成字幕。

##### 字幕切分规则

1. 先依据最终音频恢复完整断句，再删除字幕中的标点和多余空格。不能直接把没有标点的识别文本按固定字数硬切。
2. 识别文本只有空格、没有标点时，综合语义、语法、连接词、自然停顿、重音和语速补出隐藏断句。空格仅作为候选边界，不能直接视为切分结果。
3. 一条字幕只承载一个完整意群。优先在分句结束、并列结构、转折、因果、举例、列举项和自然换气处切分。
4. 单条字幕通常控制在八至十四个字符，最长不超过十六个字符。中文、数字和英文字母均按界面实际显示字符计数。
5. 字数只是约束条件。不能为了凑字数拆开人名、公司名、产品名、英文词、数字、固定搭配、介词结构或紧密相连的修饰语。
6. 避免只有一两个字、不能独立理解的碎片字幕。短字幕仅用于能够独立成立的口语词、列举序号、回答词或强调词。
7. 分条前后执行文本守恒检查：将所有字幕去除标点和空格后重新拼接，结果应与最终音频校对稿一致。校正错别字或专有名词时，单独记录修正内容，不能借分条漏字、增字或改写原话。
8. 字幕时间边界优先使用词语时间戳、实际停顿和逐句试听确定。只有分段级时间戳时，按字数比例分配只能生成候选时间，随后仍要根据最终音频调整。
9. 每条字幕要有足够阅读时间。出现一闪而过的字幕时，优先调整相邻字幕的语义切分和时间边界，不能通过漏字或把视频切碎来解决。
10. 字幕首尾连续覆盖最终保留音频，条目之间没有空白和重叠。片头第一条从有效口播开始，片尾最后一条覆盖到对应口播结束。
11. 字幕分条不得新增主视频切点。切分前后分别统计主视频片段数和字幕条数，确认主视频片段数没有因字幕增多而增加。
12. 使用 CapCut-Mate 原生 `TextSegment` 或已验证的剪映原生字幕模板生成字幕。写入后检查每条字幕都有唯一素材 ID，字幕素材数量与轨道实际引用数量一致，没有重复登记或悬空素材。
13. 保存后关闭并重新打开同一草稿，再检查字幕轨仍然存在、条数正确、文字可见且可编辑。只通过 JSON 加载、数量统计或连续性检查，不能证明字幕已在剪映中正常呈现。
14. 字幕切分验收至少记录字幕总数、最长字符数、超长条目数、含标点或空格的条目数、时间空隙或重叠数、唯一素材数，以及重开后的字幕存在性结果。

字幕统一使用以下样式：

- 字体：特黑体。
- 预设样式：白底黑字。
- 文字颜色：黑色。
- 背景颜色：白色。
- 字号：八号，按剪映参数写入八点零。
- 缩放：百分之一百。
- 位置：Y 轴负八百三十。

字体字段指向本机实际存在的特黑体字体文件，避免占位路径、临时路径或带多余空格的路径。Y 轴数值以剪映界面坐标为准；写入草稿底层结构时，根据当前画布尺寸换算为剪映需要的归一化坐标。

### 八、修复素材丢失与格式兼容问题

1. 打开草稿后检查剪映是否弹出“链接媒体”、素材数量是否为零以及预览区是否显示“媒体格式不支持”。出现这些现象时，按素材引用故障处理。
2. 定位用户确认的草稿工作区和剪映实际保存目录，再核对主轨和画中画引用的媒体路径。所有正在使用的媒体复制或转码到该草稿目录内由当前剪映版本实际使用的资源目录，不预设目录名；并用文件存在性、文件大小和媒体时长复核。
3. 如果原始素材编码导致剪映无法解码，保留完整原始文件，另制作兼容副本，优先使用剪映可稳定读取的 H.264、AAC 和常规像素格式，仅将时间线引用切换到兼容副本。
4. 修改媒体引用后，同时更新 `draft_content.json` 和 `draft_info.json`，确保媒体名称、绝对路径、素材 ID、时长及时间线引用一致。`draft_content.json` 可直接解析时做 JSON 和路径检查；如果当前版本的 `draft_info.json` 是加密或编码格式，使用剪映或剪辑工具的原生写入方式校验，不能强行将它当作 JSON，也不能使用 `draft_content.json` 直接覆盖。
5. 保存后关闭并重新打开同一个剪映草稿，确认不再弹出链接媒体窗口、预览有画面、主轨片段数量正确、字幕仍可编辑。选中任一字幕，检查字体栏显示目标字体。完成重新打开验证后，才能将素材引用故障标记为已修复。
6. 在剪辑记录中记录原始素材位置、兼容副本位置、编码变更、两份草稿元数据的同步结果和重新打开后的界面验证结果，方便后续继续编辑。

# 完成检查与交付门禁

交付前逐项检查：

1. 主内容全部在主轨，配图和辅助视频位于画中画轨道。
2. 原始素材完整保留，片段边缘可以继续延展原始素材。
3. 用户已有草稿和素材保持完整。
4. 重录清单完整，每个重录组只保留一个最佳完整版本。
5. 没有不自然的词语级拼接。
6. 最终音轨已完成第二次重复内容扫描和从头到尾的完整试听，没有卡壳重说、重复完整版本或含义重复的变体。
7. 每个上一片段都完整收尾，最后一个字的尾音没有被截断。
8. 每个下一片段在剪映最终时间线上测得的开头留白小于或等于零点零三秒，并且首音完整。
9. 每个接口均已完成放大检查和前后各零点五秒试听。
10. 片段内部的自然呼吸、重点停顿和情绪停顿得到保留。
11. 字幕为剪映可编辑字幕格式，并带有 `type=subtitle` 和 `group_id=tse_subtitle` 标记。
12. 字幕已按语义、隐藏断句和自然停顿切分；通常为八至十四个字符，最长不超过十六个字符，字幕文本中没有标点或多余空格。
13. 字幕分条前后文本守恒，没有因切分出现漏字、增字或改写；字幕之间没有时间空白或重叠。
14. 字体、颜色、背景、字号、缩放和位置符合固定要求，字体文件路径真实可用。
15. 画面、口型、声音和字幕保持同步。
16. 背景音乐和环境音连续。
17. 字幕完整覆盖最终实际录音，并已用口播稿完成语义校对。
18. 所有字幕均已逐句试听核对，没有错字、漏字、漏句、多字、字幕提前或滞后。
19. 剪辑通过 CapCut-Mate 完成，正常草稿列表中只有一个本任务目标草稿。
20. 草稿名称遵循用户和项目命名规则，且不超过四个汉字。
21. 视频没有导出，目标草稿已保存并在剪映中打开。
22. 媒体引用均指向草稿目录内的稳定文件，两份草稿元数据已同步。
23. 重新打开草稿后，没有“链接媒体”或“媒体格式不支持”提示，主轨、画中画和字幕均可正常查看和编辑。
24. 主视频片段数量与字幕片段数量分别统计，不能用字幕条数代替视频切段依据。主视频轨每个切点都有已核实的删除、重录、画面变化或音频问题原因。
25. 已完成过切复查：自然换气、短暂停顿、重点停顿和连续口播均保留，连续源片段没有因字幕分句被拆开。
26. 重复与留白删减台账完整，所有删除项均有源时间范围、判断依据、保留版本和视频、音频、字幕同步状态。
27. 最终音频由最终视频源范围重新拼接后完成二次语音识别；相邻和不相邻的重复内容均已复查，且没有字幕已删但声音仍在的情况。
28. 每个保留片段都完成内部留白审计，片段开头、结尾和内部的长空白均已删除或明确列入待用户确认清单。
29. 最终审计音频没有未经解释的长空白；自然换气、情绪停顿和转场停顿均有语义或试听依据。
30. 只完成字幕修改、只完成结构校验或只完成外部脚本扫描时，不得汇报为重复内容和空白内容均已修复。
31. 任一重复项、长空白、最终音频复查或逐句试听未完成时，交付状态必须写明未完成，并列出具体时间点，不得使用“已验收”表述。
32. 字幕素材数量与轨道实际引用数量一致，每条字幕使用唯一素材 ID，没有重复字幕素材或悬空字幕素材。
33. 重开草稿后字幕轨仍然存在，字幕条数、样式、可见性和可编辑状态均已复核；只完成文件结构校验时，不得汇报字幕已正常呈现。

向用户汇报时，说明目标草稿名称、主视频和字幕片段数量、重录组数量和保留结果、每个接口的实际开头留白范围、收尾验收结果、最终音轨试听结果、逐句字幕核对结果、素材引用和重新打开验证结果、需要用户确认的时间点，以及视频未导出且已保留在剪映草稿中。任一项未完成时，必须明确说明未完成，不得汇报为已验收。
